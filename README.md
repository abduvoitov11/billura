# Billura 🤎

Faqat Billura uchun maxsus romantik veb-sahifa.

### 🌟 Xususiyatlari:
- **Interaktiv xat (Wax Seal):** Brauzerlar cheklovini yenguvchi interaktiv ochilish konverti
- **Vertikal video:** Reels / Stories formatidagi sevgi izhori va musiqali video
- **Interaktiv taklif:** "Albatta" va o'ynoqi qochuvchi "O'ylab ko'raman" tugmasi
- **Bayramona tabrik:** Yuraklar va samimiy so'zlar bilan yakun
